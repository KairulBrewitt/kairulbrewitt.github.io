# kairulbrewitt.github.io

The GitHub Pages **user site** for this account. It exists to serve two things at
the domain root, which a project site (`/minato-studio/`) cannot do:

- `app-ads.txt` — the IAB authorized-sellers file. AdMob crawls
  `https://kairulbrewitt.github.io/app-ads.txt` because that domain is the
  developer website on the TabiLog and TabiPlanner Play listings. Without it,
  both apps sit in "Limited ad serving".
- `index.html` — a redirect so the bare domain lands on the real site.

The site itself is at https://github.com/KairulBrewitt/minato-studio.

If a mediation partner is ever added in AdMob, its line goes in `app-ads.txt`
too, or that partner's demand stops serving.
